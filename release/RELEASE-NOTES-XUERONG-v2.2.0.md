# 雪絨 2.2.0

- 全部 24 個實際使用中的一般與迷你動畫以 RIFE v4.6 補幀到約 30 FPS。
- 保留各動作原本總時長；睡眠的長閉眼停留不會被加速。
- 透明度與預乘色彩分開補幀，避免白髮、蝴蝶結和筆電邊緣產生黑暈。
- 以一般待機高度為基準驗證直立動作，並檢查每個補間幀的身高與腳底位置。
- 右鍵進入迷你模式改為一般比例走向最近邊緣，不再二次飛出與瞬移。
- 長距離進入迷你模式時會在途中轉一圈；直接拖曳進入迷你模式的行為維持不變。

主題 EXE／ZIP 可安裝於 Clawd on Desk 0.12.0。右鍵走路與轉圈需要搭配移植過的 0.12.0 核心，單純主題安裝不會修改 `app.asar`。
